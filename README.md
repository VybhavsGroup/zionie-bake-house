# Zionie Bake House 🧁

Official website for **Zionie Bake House** — a home bakery in Coimbatore crafting
brownies, custom celebration cakes, cupcakes and tea cakes, plus signature millet
bakes (ragi, karuppu kavuni & wheat). *Every bites are yummy.*

## Features

- **WhatsApp ordering** — the order and class-enrollment forms open WhatsApp with
  the request pre-filled (no backend needed)
- **Menu** with category filters: Brownies & Blondies, Cupcakes, Tea & Pudding
  Cakes, Millet Varieties, and 8 customized-cake flavours
- **Baking classes** with schedules and reservation form
- **Reviews** and a **photo gallery** of real bakes with a lightbox
- Fully responsive, elegant reveal animations, `prefers-reduced-motion` support

## Stack

Plain HTML + CSS + vanilla JavaScript — no frameworks, no build step.
Open `index.html` in a browser or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

`tools/build-onefile.py` bundles the entire site (styles, scripts and photos inlined)
into a single portable HTML file.
